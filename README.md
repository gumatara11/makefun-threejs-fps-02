DUSTLINE is a round-based tactical FPS in three.js: plant or defuse the bomb on Foundry Yard's two sites, or eliminate the defenders, in a first-to-5 3v3 match with bots, a buy economy, and two weapons.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
